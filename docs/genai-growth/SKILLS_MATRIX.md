# GenAI Skills Matrix

## Status Definitions
- **NOT STARTED** — no meaningful implementation yet
- **LEARNING** — actively exploring or using in a limited/non-production way
- **IMPLEMENTED** — working implementation exists in development/test
- **DEPLOYED** — running in production
- **PRODUCTION VALIDATED** — deployed and supported by real usage, evaluation, monitoring, or operational evidence

## Review Rule
After every major milestone:
1. Update relevant rows.
2. Add concrete evidence.
3. Do not move directly to PRODUCTION VALIDATED merely because code was deployed.
4. Record what still needs to be demonstrated.
